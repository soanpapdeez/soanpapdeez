## 🚀 Featured Projects

### 📖 Etude: AI-Powered Living Academic Intelligence System
`Python` `LangChain` `ChromaDB` `Ollama`

A RAG system that turns college slides and textbooks into syllabus-accurate notes, Q&A, quizzes, and flashcards.
- Syllabus-diff engine that flags outdated content each semester
- Fully local inference (Phi-3 Mini / Gemma 2B via Ollama) with zero API or cloud cost
- Enforced source attribution to prevent hallucinated answers

### 🆘 ARDEM: AI-Assisted Disaster Reconnaissance Module *(in progress)*
`ESP32` `UWB` `IMU` `SLM`

A reconnaissance device for collapsed structures.
- Sensor pipeline (ESP32, UWB, IMU) for occupancy mapping: free space / obstacle / unknown
- Small language model that translates sensor readings into human-readable rescue recommendations

### 📊 Application Monitoring Dashboards
`FastAPI` `Kafka` `MySQL` `Grafana`

An analytics platform that tracks system performance metrics in real time for proactive debugging, with MySQL storage and Grafana visualization.

### 🎵 Music Mood Analyzer
`Kafka` `Spark Streaming` `MySQL`

Processes live audio data to classify song moods from audio features, storing results in MySQL and visualizing trends on an interactive dashboard.
